# ASTA — From Kashmir, With Purity

Premium Kashmiri brand website for pure honey, saffron, Kahwa and dry fruits.

## Features
- Luxury ivory / charcoal / antique-gold design
- Product showcase with weight variants
- **No prices on the website** — customers inquire via WhatsApp and receive pricing there
- WhatsApp-first ordering (Get Price / Order buttons on every product)
- Floating WhatsApp button
- Search, wishlist, product detail modal
- Our Story + Contact sections with official brand copy
- Fully responsive

## How to run locally
1. Place the two product images in `images/`:
   - `IMG-20260812-WA0012.jpg` (Honey packaging)
   - `IMG-20260812-WA0011.jpg` (Kahwa jar)
2. Open `index.html` in a browser, or run:
```bash
python3 -m http.server 8080
```

## Deploy
Deploy the folder to Vercel, Netlify, or any static host.
